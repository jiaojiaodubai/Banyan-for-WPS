## 快速开始

### 前置条件

在使用 Banyan WPS 插件之前，请确保：

1. ✅ 已安装 WPS Office
2. ✅ 已安装 Zotero 文献管理软件
3. ✅ 已在 Zotero 中安装并启用 Banyan 插件
4. ✅ Zotero 正在运行

### 首次使用

1. **打开 WPS 文档**
   - 启动 WPS Writer
   - 打开或创建一个文档

2. **查看 Banyan 选项卡**
   - 在 WPS 顶部功能区找到"Banyan"选项卡
   - 您将看到 8 个功能按钮

3. **配置引用样式**
   - 点击"设置"按钮
   - 点击"获取样式"按钮
   - 在 Zotero 中选择您需要的引用样式
   - 点击"确定"保存设置

4. **开始引用**
   - 将光标放在需要插入引注的位置
   - 点击"插入/编辑引注"按钮
   - 在 Zotero 中选择要引用的文献
   - 引注将自动插入到文档中

## 详细使用指南

### 1. 插入/编辑引注

#### 插入新引注

**步骤：**

1. 将光标放在需要插入引注的位置
2. 点击"插入/编辑引注"按钮
3. Zotero 窗口将弹出，显示您的文献库
4. 选择要引用的文献（可多选）
5. 根据需要设置引注选项：
   - 页码（如 p. 123）
   - 前缀（如"参见"）
   - 后缀（如"及其他"）
   - 隐藏作者（仅显示年份）
6. 点击"确定"
7. 引注将插入到文档中

**视觉反馈：**

- 点击插入后，文档会先出现红色占位引注（如 `{ INTEXT_CITATION }` / `{ NOTE_CITATION }`）
- 后端返回后会自动替换为最终渲染结果

**示例：**

- 正文引注样式：`(Smith, 2020)`
- 脚注引注样式：文中显示上标数字，脚注中显示完整引用

#### 编辑现有引注

**步骤：**

1. 将光标放在引注内部或选中引注
2. 点击"插入/编辑引注"按钮
3. 在 Zotero 窗口中修改引注：
   - 添加或删除文献
   - 修改页码、前缀、后缀等
4. 点击"确定"
5. 引注将自动更新

**提示：**

- 如果引注显示为红色 `{ INTEXT_CITATION }` 或 `{ NOTE_CITATION }`，说明引注需要刷新或重新插入
- 插入或编辑引注后，插件会自动刷新
- 使用脚注引注样式时，请将光标放在正文中的脚注引用标记（上标编号）处再点击按钮进行编辑

### 2. 插入章节分隔符

#### 什么是章节分隔符？

章节分隔符用于将文档分成多个独立的章节，每个章节可以使用不同的引用样式。

**使用场景：**

- 学位论文：不同章节使用不同引用样式
- 合集：多个作者的文章合并在一个文档中
- 多语言文档：中文章节和英文章节使用不同样式

#### 插入分隔符

**步骤：**

1. 将光标放在章节开始位置（通常是章节标题前）
2. 确保已在设置中选择引用样式
3. 点击"插入分隔符"按钮
4. 分隔符将插入到文档中，显示为红色文本：

   ```text
   ==========Banyan章节分隔符（请勿编辑）==========
   ```

**注意事项：**

- 分隔符必须插入在主文档正文中（不能在页眉、页脚、文本框等）
- 分隔符不能插入在域代码内部
- 分隔符是锁定的，防止误编辑
- 按 `Alt+F9` 可以切换显示/隐藏分隔符

#### 管理章节

- **查看章节：** 按 `Alt+F9` 显示所有分隔符
- **删除章节：** 选中分隔符，按 `Delete` 键
- **修改章节样式：** 在分隔符后的区域打开设置，选择新样式

### 3. 插入/编辑参考文献表

#### 插入参考文献表

**步骤：**

1. 确保文档中已有引注
2. 将光标放在要插入参考文献表的位置（通常是文档末尾）
3. 点击"插入/编辑书目"按钮
4. 插件将自动：
   - 收集当前章节的所有引注
   - 生成参考文献表
   - 应用格式样式

**视觉反馈：**

- 插入过程中会先显示红色临时占位文本 `{ BIBLIOGRAPHY }`
- 数据返回后自动替换为最终参考文献表

**参考文献表结构：**

```text
参考文献（标题，可选）

[1] Smith, J. (2020). Title of the article. Journal Name, 10(2), 123-145.
[2] Johnson, M. (2019). Title of the book. Publisher.
...
```

#### 编辑参考文献条目

**步骤：**

1. 将光标放在参考文献条目内部
2. 点击"插入/编辑书目"按钮
3. 在 Zotero 窗口中编辑条目信息
4. 点击"确定"
5. 条目将自动更新

**提示：**

- 参考文献表会自动排序（根据样式规则）
- 只显示被引用的文献
- 可以在设置中添加未引用的文献

### 4. 打开引注窗格

#### 什么是引注窗格？

引注窗格是一个侧边栏，显示当前章节的所有引注，方便您查看和管理。

#### 使用引注窗格

**步骤：**

1. 点击"打开引注窗格"按钮
2. 窗格将在 WPS 右侧打开

**窗格功能：**

- **查看引注列表：** 显示所有引注的预览文本和页码
- **展开/折叠：** 点击引注左侧的箭头，查看包含的文献
- **跳转到引注：** 点击引注，文档将自动滚动到该位置
- **刷新列表：** 点击"刷新"按钮，重新加载引注
- **切换章节：** 使用"上一章节"和"下一章节"按钮

**提示：**

- 窗格会自动同步主题（亮色/暗色）
- 当前选中的引注会高亮显示
- 窗格可以调整宽度

### 5. 刷新

#### 什么时候需要刷新？

- 修改了 Zotero 中的文献信息
- 更改了引用样式
- 引注显示为红色 `{ INTEXT_CITATION }` 或 `{ NOTE_CITATION }`
- 参考文献表显示为红色 `{ BIBLIOGRAPHY }`
- 参考文献表格式不正确

#### 刷新操作

**步骤：**

1. 点击"刷新"按钮
2. 插件将自动：
   - 更新所有引注的格式
   - 重新生成参考文献表
   - 同步文献元数据（如果启用）

**刷新范围：**

- **当前章节：** 只刷新光标所在章节（默认）
- **所有章节：** 刷新整个文档（在设置中启用）

**提示：**

- 刷新可能需要几秒到几分钟（取决于引注数量）
- 刷新时会显示进度提示
- 刷新不会修改引注的内容，只更新格式

### 6. 定稿

#### 什么是定稿？

定稿是将文档中的所有 Banyan 域代码转换为纯文本的过程。这是提交论文前的最后一步。

**为什么需要定稿？**

- 域代码可能在其他软件中显示异常
- 某些期刊要求提交纯文本文档
- 防止他人修改引注

#### 定稿操作

**步骤：**

1. **保存文档：** 确保文档已保存
2. **检查引注：** 确认所有引注和参考文献都正确
3. **点击"定稿"按钮**
4. **阅读确认对话框：**

   ```plaintext
   执行"定稿"会将 Banyan 域代码替换为当前显示结果，且不可撤销。
   
   系统会先自动备份当前文档，再继续执行。
   
   是否继续？
   ```

5. **点击"确定"**
6. **等待处理：** 插件将：
   - 创建备份文件
   - 转换所有域代码
   - 删除章节分隔符
7. **查看结果：** 对话框显示处理统计

**备份文件：**

- 位置：与原文档相同目录
- 命名：`原文件名-MM-DD HH-MM-SS.扩展名`
- 示例：`论文-04-25 14-30-00.docx`

**⚠️ 重要提示：**

- 定稿后无法撤销，请务必检查备份文件
- 定稿后无法再使用 Banyan 功能编辑引注
- 建议在定稿前创建一个副本

### 7. 设置

#### 打开设置

点击"设置"按钮，打开设置对话框。

#### 全局设置

**同步条目元数据：**

- ✅ 启用：刷新时从 Zotero 同步最新的文献信息
- ❌ 禁用：只在插入/编辑引注时同步

**刷新所有章节：**

- ✅ 启用：点击"刷新"按钮时刷新整个文档
- ❌ 禁用：只刷新当前章节

#### 章节设置

**引用样式：**

- 点击"获取样式"按钮
- 在 Zotero 中选择样式
- 样式名称将显示在输入框中

**参考文献标题样式：**

- 输入 WPS 样式名称（如"标题 1"）
- 用于格式化参考文献表的标题行
- 留空则使用默认样式

**参考文献条目样式：**

- 输入 WPS 样式名称（如"正文"）
- 用于格式化参考文献表的条目
- 留空则使用默认样式

**提示：**

- 样式名称区分大小写
- 如果样式不存在，插件会自动创建
- 点击"清除"按钮可以清空样式名称

### 8. 暗色主题

#### 切换主题

点击"暗色主题"按钮，在亮色和暗色主题之间切换。

**主题效果：**

- **Ribbon 图标：** 自动切换为适合当前主题的颜色
- **设置对话框：** 自动切换背景和文字颜色
- **引注窗格：** 自动切换背景和文字颜色

**主题同步：**

- 主题设置会自动保存
- 下次打开 WPS 时会恢复上次的主题
- 所有窗口会自动同步主题

## 常见问题

### 安装和配置

**Q1: 如何安装 Banyan WPS 插件？**

A: 请参考 Banyan 插件的官方文档进行安装。

**Q2: 插件无法连接到 Zotero，怎么办？**

A: 请检查：

1. Zotero 是否正在运行
2. Banyan 插件是否已在 Zotero 中启用
3. Zotero HTTP Server 是否使用标准端口 23119 或调试端口 23124

**Q3: 可以更改 Zotero 服务器端口吗？**

A: WPS 插件优先连接 Zotero 标准端口 23119，连接失败时自动尝试调试端口 23124。目前不支持其他端口。

### 使用问题

**Q4: 引注显示为红色 { INTEXT_CITATION } 或 { NOTE_CITATION }，怎么办？**

A: 这表示引注需要刷新或插入未完成。先点击"刷新"按钮；如果仍未更新，请删除该占位域后重新插入。

**Q5: 如何在文档中使用多个引用样式？**

A: 使用章节分隔符。在每个章节开始位置插入分隔符，然后为该章节选择样式。

**Q6: 参考文献表没有自动更新，怎么办？**

A: 点击"刷新"按钮。如果显示红色 `{ BIBLIOGRAPHY }` 或问题仍然存在，删除参考文献表后重新插入。

**Q7: 如何添加未引用的文献到参考文献表？**

A:

1. 在参考文献表中选择一个条目
2. 点击"插入/编辑书目"按钮
3. 在 Zotero 中添加未引用的文献
4. 点击"确定"

**Q8: 定稿后发现错误，如何恢复？**

A:

1. 关闭当前文档（不保存）
2. 打开备份文件（文件名包含时间戳）
3. 修改错误
4. 重新定稿

**Q9: 引注窗格显示"未找到引注"，怎么办？**

A:

1. 确保文档中有引注
2. 点击窗格中的"刷新"按钮
3. 如果使用了章节分隔符，确保光标在正确的章节中

**Q10: 如何删除所有 Banyan 引注？**

A:

1. 使用"定稿"功能（会保留引注文本）
2. 或者手动删除每个引注域

### 格式问题

**Q11: 引注格式不正确，怎么办？**

A:

1. 检查 Zotero 中的文献信息是否完整
2. 确认选择了正确的引用样式
3. 点击"刷新"按钮

**Q12: 参考文献表的格式如何自定义？**

A:

1. 在设置中指定 WPS 样式名称
2. 在 WPS 中修改该样式的格式（字体、行距等）
3. 点击"刷新"按钮应用新格式

**Q13: 如何更改引注的字体或颜色？**

A:

1. 在 WPS 中创建或修改"Banyan 引注"样式
2. 点击"刷新"按钮应用新样式

### 性能问题

**Q14: 刷新很慢，怎么办？**

A:

1. 在设置中禁用"同步条目元数据"
2. 在设置中禁用"刷新所有章节"
3. 使用章节分隔符，只刷新当前章节

**Q15: 文档很大，插件响应慢，怎么办？**

A:

1. 将文档拆分为多个小文档
2. 使用章节分隔符
3. 定期保存文档

### 错误处理

**Q16: 插件报错，怎么办？**

A:

1. 记录错误信息
2. 重启 WPS 和 Zotero
3. 检查文档是否损坏
4. 联系技术支持

**Q17: 域代码损坏，怎么办？**

A:

1. 删除损坏的域
2. 重新插入引注
3. 如果问题严重，恢复备份文件

- ✅ 检查引注和参考文献
- ✅ 执行定稿操作
- ✅ 检查备份文件

### 协作写作

#### 多人协作建议

1. **统一环境：**
   - 所有人使用相同版本的 WPS、Zotero 和 Banyan
   - 使用相同的引用样式

2. **分工明确：**
   - 指定一人负责引注管理
   - 其他人只负责写作

3. **版本控制：**
   - 使用文件命名规范（如"论文-v1.0-2026-04-25.docx"）
   - 定期创建备份

4. **合并文档：**
   - 使用章节分隔符分隔不同作者的内容
   - 合并前确保所有引注都已刷新

### 样式选择

#### 常见学科的引用样式

| 学科     | 推荐样式                                 | 类型 |
|----------|------------------------------------------|------|
| 人文社科 | Chicago Manual of Style                  | 脚注 |
| 社会科学 | APA (American Psychological Association) | 正文 |
| 自然科学 | Nature                                   | 正文 |
| 医学     | Vancouver                                | 正文 |
| 工程技术 | IEEE                                     | 正文 |
| 法学     | Bluebook                                 | 脚注 |

#### 如何选择样式

1. **查看期刊要求：** 大多数期刊会指定引用样式
2. **咨询导师：** 学位论文应遵循学校或导师的要求
3. **参考同行：** 查看同领域论文使用的样式

### 性能优化

#### 大文档优化技巧

1. **使用章节分隔符：**
   - 将大文档分成多个章节
   - 只刷新当前编辑的章节

2. **控制刷新范围：**
   - 在设置中关闭“刷新所有章节”后，点击“刷新”只更新当前章节

3. **减少引注数量：**
   - 合并相邻的引注
   - 使用"ibid."等缩写（如果样式支持）

4. **定期清理：**
   - 删除未使用的引注
   - 删除重复的参考文献条目

### 备份策略

#### 建议的备份方案

1. **自动备份：**
   - 启用 WPS 的自动保存功能
   - 设置较短的保存间隔（如 5 分钟）

2. **手动备份：**
   - 每天结束时创建一个备份
   - 重要节点（如完成一章）创建备份

3. **云备份：**
   - 使用云存储服务（如 OneDrive、百度网盘）
   - 启用自动同步

4. **版本命名：**
   - 使用有意义的文件名
   - 包含日期和版本号
   - 示例：`论文-第一章-v1.2-2026-04-25.docx`

### 术语表

- **引注（Citation）：** 文档中引用文献的标记
- **参考文献表（Bibliography）：** 文档末尾列出的所有引用文献
- **域（Field）：** WPS 中的动态内容，可以自动更新
- **章节分隔符（Chapter Break）：** 用于分隔不同引用样式的标记
- **定稿（Finalize）：** 将域代码转换为纯文本
- **刷新（Refresh）：** 更新引注和参考文献的格式

### 配置位置

- **插件设置：** `Application.PluginStorage`
- **文档设置：** 存储在文档自定义属性（`CustomDocumentProperties`，属性名 `BANYAN_PREF`）中
- **章节设置：** 存储在章节分隔符域中（第一章的章节设置与文档设置一同存储）

### 支持的引用样式类型

- **正文引注（Intext Citation）：** 如 APA、MLA、Chicago（作者-日期）
- **脚注引注（Note Citation）：** 如 Chicago（脚注）、Turabian

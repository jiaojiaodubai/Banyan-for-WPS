# Banyan for WPS - 特性目标

本文档定义了 Banyan for WPS 必须实现的功能特性。任何代码改动如果影响了这些特性，必须在此文档中说明并获得批准后更新。

## 核心功能

### 1. 引注管理

#### 1.1 插入引注

**功能描述**：在文档中插入新的引注

**必须支持**：

- 正文引注（intext-citation）：直接插入在正文中
- 脚注引注（note-citation）：以脚注形式插入

**操作流程**：

1. 用户将光标放在需要插入引注的位置
2. 点击"插入/编辑引注"按钮
3. 系统检查光标位置（必须在主文档正文中）
4. 系统检查是否已选择引用样式
5. 调用 Zotero 选择文献
6. 在获得后端返回前，创建默认域，并渲染红色默认内容 `{ INTEXT_CITATION }` 或 `{ NOTE_CITATION }` 作为视觉反馈，以免意外无法渲染时，用户误以为没插入域
7. 用后端获取的数据替换默认数据并渲染
8. 应用样式

**约束条件**：

- 光标必须在主文档正文中（不能在页眉、页脚、文本框等）
- 必须先设置引用样式
- 引注类型由样式决定（in-text 或 note）

#### 1.2 编辑引注

**功能描述**：编辑已存在的引注

**必须支持**：

- 修改引用的文献
- 添加/删除文献
- 修改页码、前缀、后缀等参数

**操作流程**：

1. 用户将光标放在已有引注上
2. 点击"插入/编辑引注"按钮
3. 系统识别当前引注
4. 调用 Zotero 编辑引注
5. 更新域数据和渲染结果

**约束条件**：

- 光标必须在引注域内；脚注引注需将光标置于正文中的脚注引用标记处
- 保持引注 UUID 不变

### 2. 参考文献表管理

#### 2.1 插入参考文献表

**功能描述**：在文档中插入参考文献表

**必须支持**：

- 自动收集当前章节的所有引注
- 生成参考文献列表
- 可选的标题行
- 每个条目一个段落

**操作流程**：

1. 用户将光标放在需要插入参考文献表的位置
2. 点击"插入/编辑书目"按钮
3. 系统收集当前章节的所有引注
4. 创建红色临时占位域，并渲染默认内容 `{ BIBLIOGRAPHY }` 作为视觉反馈
5. 调用 Zotero 生成参考文献表
6. 删除现有参考文献表（如果存在）
7. 插入新的参考文献表
8. 应用样式
9. 为每个条目添加书签

**约束条件**：

- 光标必须在主文档正文中
- 必须先设置引用样式
- 每个章节只能有一个参考文献表

#### 2.2 编辑参考文献条目

**功能描述**：手动添加未引用的文献到参考文献表

**必须支持**：

- 在 Zotero 中选择要添加的文献
- 将文献添加到章节设置的 extraSource 中
- 重新生成参考文献表

**操作流程**：

1. 用户将光标放在参考文献条目上
2. 点击"插入/编辑书目"按钮
3. 调用 Zotero 选择文献
4. 更新章节设置
5. 重新生成参考文献表

### 3. 刷新功能

#### 3.1 刷新引注和参考文献

**功能描述**：更新文档中的引注和参考文献

**必须支持**：

- 刷新当前章节
- 刷新所有章节（可选）
- 批量处理所有引注
- 更新参考文献表

**操作流程**：

1. 用户点击"刷新"按钮
2. 系统确定刷新范围（当前章节或全部章节）
3. 收集范围内的所有引注
4. 批量调用 Zotero 刷新
5. 更新每个引注的域数据和渲染结果
6. 更新参考文献表
7. 为参考文献条目添加书签

**约束条件**：

- 必须批量请求，不能逐个请求
- 必须显示进度提示
- 单个引注失败不影响其他引注

#### 3.2 自动刷新

**功能描述**：插入/编辑引注后自动刷新

**必须支持**：

- 插入引注后自动刷新
- 编辑引注后自动刷新

**约束条件**：

- 插入/编辑引注成功后总是自动刷新，刷新范围由全局设置 `refreshAll` 决定（全部章节或当前章节）

### 4. 章节分隔符

#### 4.1 插入章节分隔符

**功能描述**：在文档中插入章节分隔符，用于分隔不同引用样式的章节

**必须支持**：

- 在光标位置插入分隔符
- 存储章节级设置（样式、extraSource 等）
- 显示为红色域代码
- 锁定状态（防止误编辑）

**操作流程**：

1. 用户将光标放在需要插入分隔符的位置
2. 点击"插入分隔符"按钮
3. 系统检查光标位置（必须在段落开头）
4. 插入章节分隔符域
5. 设置域格式（红色、锁定）

**约束条件**：

- 光标必须在段落开头
- 光标必须在主文档正文中

#### 4.2 章节设置

**功能描述**：为每个章节独立设置引用样式和参考文献样式

**必须支持**：

- 引用样式（style）
- 手动添加的未引用文献（extraSource）
- 参考文献标题样式（bibliographyTitleStyle）
- 参考文献条目样式（bibliographyEntryStyle）

**存储位置**：章节分隔符域的 Data 属性（第一章的章节设置与全局设置一同存放在文档属性 `BANYAN_PREF` 中，插入分隔符时随域数据一并保存）

### 5. 文档定稿

#### 5.1 解除域链接

**功能描述**：将所有 Banyan 域代码转换为纯文本，用于最终提交

**必须支持**：

- 自动备份当前文档
- 解除引注域链接（保留渲染结果）
- 解除参考文献域链接（保留渲染结果）
- 删除章节分隔符（不保留任何内容）

**操作流程**：

1. 用户点击"定稿"按钮
2. 系统显示确认对话框
3. 用户确认后，系统备份文档
4. 遍历所有 Banyan 域
5. 解除域链接或删除域
6. 显示处理统计信息

**约束条件**：

- 必须先备份文档
- 备份失败则中止操作
- 备份文件命名：`原文件名-MM-DD HH-MM-SS.扩展名`
- 使用原子性文件替换

### 6. 引注窗格

#### 6.1 显示引注列表

**功能描述**：在任务窗格中显示当前章节的所有引注

**必须支持**：

- 显示引注预览文本
- 显示引注所在页码
- 显示引注包含的条目列表（可展开/折叠）
- 点击引注跳转到文档位置
- 点击条目在 Zotero 中定位

**操作流程**：

1. 用户点击"打开引注窗格"按钮
2. 系统创建或显示任务窗格
3. 收集当前章节的所有引注
4. 渲染引注列表

**约束条件**：

- 任务窗格只能有一个实例
- 支持主题同步

#### 6.2 章节导航

**功能描述**：在任务窗格中切换章节

**必须支持**：

- 上一章节按钮
- 下一章节按钮

**操作流程**：

1. 用户点击上一章节/下一章节按钮
2. 系统查找上一个/下一个章节分隔符
3. 移动光标到该章节
4. 刷新引注列表

### 7. 设置管理

#### 7.1 全局设置

**功能描述**：管理文档级别的全局设置

**必须支持**：

- 同步条目元数据（syncItems）
- 刷新所有章节（refreshAll）

**存储位置**：文档自定义属性（`CustomDocumentProperties`）中的 `BANYAN_PREF`（JSON 编码）

#### 7.2 章节设置

**功能描述**：管理章节级别的设置

**必须支持**：

- 获取当前样式
- 设置引用样式
- 设置参考文献样式

**操作流程**：

1. 用户点击"设置"按钮
2. 系统显示设置对话框
3. 用户修改设置
4. 点击"确定"保存设置
5. 如果当前章节的引用样式发生变化，系统按新样式刷新当前章节的引注和参考文献表

**约束条件**：

- 设置对话框必须支持主题同步
- 必须验证用户输入
- 当引用样式在 `intext-citation` 与 `note-citation` 之间切换时，必须先迁移当前章节内已有引注的结构，再执行刷新

### 8. 自应用 Word 样式

**功能描述**：为引注和文献列表自动应用特定的 Word 样式，以便用户可以全选批量修改，或设置更复杂的排版格式。

**样式名称**：

- 引注样式（字符样式）：简体中文环境为 `Banyan 引注`，英语环境为 `Banyan Citation`
- 参考文献标题样式（段落样式）：名称由章节设置的 `bibliographyTitleStyle` 指定，缺省为 `文献列表标题` / `Bibliography Title`
- 参考文献条目样式（段落样式）：名称由章节设置的 `bibliographyEntryStyle` 指定，缺省为 `文献列表题录` / `Bibliography Entry`

**样式创建规则**：

- 如果样式不存在，自动创建
- 基于 WPS 默认样式
- 不覆盖用户自定义样式

### 9. 主题支持

#### 9.1 亮色/暗色主题切换

**功能描述**：支持亮色和暗色主题

**必须支持**：

- Ribbon 按钮图标切换
- 任务窗格主题切换
- 设置对话框主题切换
- 主题状态持久化

**同步机制**：

**BroadcastChannel 同步**：

- 频道名称：`banyan-theme-sync`
- 消息格式：

  ```javascript
  {
    type: "theme-changed",
    mode: "light" | "dark",
    ts: number
  }
  ```

**回退机制**：

1. BroadcastChannel（实时同步，优先）
2. 窗口获得焦点时重新读取 `Application.PluginStorage` 中的主题状态（回退）

**约束条件**：

- 主题状态必须在所有窗口间同步
- 主题状态必须持久化到 `Application.PluginStorage`

### 9. 国际化

#### 9.1 多语言支持

**功能描述**：支持多语言界面

**必须支持**：

- 简体中文（中国大陆、新加坡）
- 英语（美国）

**约束条件**：

- 根据 WPS 语言自动选择
- 不支持的语言回退到英语

## 性能要求

### 1. 响应时间

- 插入/编辑引注：< 2 秒（不含 Zotero 选择时间）
- 刷新单个章节（< 50 个引注）：< 5 秒
- 刷新全部章节（< 200 个引注）：< 20 秒
- 打开任务窗格：< 1 秒

### 2. 批量操作

- 刷新时必须批量请求所有引注，不能逐个请求
- 倒序遍历域集合，避免删除时索引变化

### 3. 进度提示

- 长时间操作（> 1 秒）必须显示进度提示
- 使用 `withProgress` 包裹操作

## 兼容性要求

### 1. WPS 版本

- 支持 WPS Office 2019 及以上版本
- 支持 Windows 平台

### 2. Zotero 版本

- 支持 Zotero 6.0 及以上版本
- 需要安装 Banyan 插件

## 安全要求

### 1. 数据验证

- 所有从域读取的数据必须经过类型守卫验证
- HTTP 响应数据必须验证
- 用户输入必须验证

### 2. 错误隔离

- 单个域处理失败不能影响其他域
- 网络错误不能导致插件崩溃

### 3. 备份机制

- 定稿前必须自动备份
- 备份失败则中止操作

### 4. 权限最小化

- 只访问必要的 WPS API
- 只修改 Banyan 创建的域

## 用户体验要求

### 1. 错误提示

- 网络错误 → 提示启动 Zotero
- 用户取消 → 静默返回（不显示错误）
- 其他错误 → 显示清晰的错误信息

### 2. 操作反馈

- 长时间操作显示进度条
- 操作完成显示成功提示
- 操作失败显示错误信息

### 3. 界面一致性

- 所有对话框支持主题同步
- 所有按钮有清晰的图标和标签
- 所有输入框有实时验证
